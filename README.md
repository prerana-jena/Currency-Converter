# Advanced Currency Converter

A Java-based currency converter application demonstrating core Java concepts including OOP, exception handling, collections, interfaces, and modular programming.

## Features
- Currency conversion
- Menu-driven console application
- Dynamic exchange rate update
- Input validation
- Exception handling
- Object-Oriented Design

## Technologies Used

- OOP Concepts
- Collections Framework

- Interfaces
